5. UNDERSTAND DOMINICK'S BEFORE MODELING
======================================================================

Treat the official manual as schema source of truth.

Relevant movement fields include:

    upc
    store
    week
    move
    price
    qty
    profit
    sale
    ok

From the official manual:

- move = number of individual units sold
- price can be the total price of a bundle
- qty = number of items in the bundle
- total dollar sales = price * move / qty
- profit = gross margin percentage
- sale codes:
      B = Bonus Buy
      C = Coupon
      S = simple price reduction
- promotion coding is incomplete:
      if a code is present it indicates promotion,
      but missing code does NOT prove that no promotion occurred
- ok = 1 valid, 0 suspect/trash according to the data documentation

The wholesale/accounting cost underlying the margin is Average Acquisition Cost (AAC),
not necessarily economic replacement cost.

Therefore use precise derived names:

    effective_unit_price = price / qty

    revenue = effective_unit_price * move

    gross_margin_rate = profit / 100

    estimated_unit_aac =
        effective_unit_price * (1 - gross_margin_rate)

    gross_profit =
        revenue * gross_margin_rate

Never rename estimated_unit_aac to a generic "true_unit_cost".

Document explicitly:
AAC is an accounting inventory acquisition measure and can differ from the economically relevant replacement cost.

- hold appropriate non-price context fixed,
- predict demand,
- compute expected revenue,
- compute expected gross profit.

Important:
Historical margin `profit` is NOT itself a fixed counterfactual margin.
For candidate price simulation, use a fixed known AAC/cost assumption:

    expected_gross_profit(p)
      = (p - known_aac) * predicted_units(p)

Do not reuse the observed historical margin percentage unchanged when changing candidate price.
That would be mechanically wrong.

Define the decision-time cost as:
- latest known / lagged estimated AAC,
or another explicitly documented cost rule.

Create tests proving cost is held fixed across a candidate price simulation
unless a scenario explicitly changes cost.
