# How this project was built

This repository was built with AI coding assistants (Claude Code and Codex)
working from the two briefs in this folder:

* `AI_Pricing_Revenue_Optimization_Claude_Codex_Master_Prompt.txt` is the
  original project brief. It covers scope, dataset, phases and acceptance
  criteria.
* `Claude Code Prompt — Ultra-Detailed Full Project Report.md` is the brief
  for the full technical report in `reports/`.

They are kept for transparency, not as documentation of the system. The
authoritative description of what was built, and why, is in `README.md`,
`DECISIONS.md`, `docs/TECHNICAL_DESIGN.md` and the generated reports. Every
number in those comes from running the pipeline, not from these briefs.
